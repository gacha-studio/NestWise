# 板取ちゃん Web版

板材の寸法・枚数と切り出す部品を入力し、板取り計算と切断図を表示するブラウザーアプリです。

## 使い方

`index.html` をブラウザーで開いてください。インストールやデータベースは不要です。

入力内容と計算結果はブラウザーを開いている間だけ保持します。画面を閉じると消えます。「新規計算」でも入力と結果を初期化できます。

## GitHub Pages

このリポジトリをGitHubに登録した後、リポジトリの **Settings → Pages** で公開元を **Deploy from a branch**、ブランチを `main`、フォルダーを `/(root)` に設定します。公開されるまで数分かかる場合があります。

## ファイル

- `index.html`: 画面構造
- `style.css`: 表示とレイアウト
- `app.js`: 入力処理と板取り計算
