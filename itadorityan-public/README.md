# 板取ちゃん Web版

複数の板材寸法・枚数と切り出す部品を入力し、板取り計算と切断図を表示するブラウザーアプリです。板材の組み合わせは最大5秒探索し、その間に見つかった候補から使用率の高い結果を選びます。全配置の最適解を保証するものではありません。

## 使い方

`index.html` をブラウザーで開いてください。インストールやデータベースは不要です。

入力内容はこの端末のブラウザー保存領域に保持し、同じブラウザーで次回開いたときに復元します。「新規計算」で保存内容を消去します。計算結果は画面を閉じると消え、保存しません。

## GitHub Pages

このリポジトリをGitHubに登録した後、リポジトリの **Settings → Pages** で公開元を **Deploy from a branch**、ブランチを `main`、フォルダーを `/(root)` に設定します。公開されるまで数分かかる場合があります。

## ファイル

- `index.html`: 画面構造
- `style.css`: 表示とレイアウト
- `app.js`: 入力処理と板取り計算



配置図の部品はタップまたはクリックで90度回転できます。回転した部品の位置と向きを固定して、同じ板のほかの部品を最大5秒詰め直します。すべて配置できない場合は、回転だけを反映して周囲の部品を動かしません。ほかの板へ部品を移すことはありません。
